# MusicSafe para Windows

Este repositorio distribui apenas os instaladores oficiais do MusicSafe. O codigo-fonte e mantido em um repositorio privado.

Os instaladores e as notas de versao ficarao em [Releases](https://github.com/MkDesignWeb/MusicSafe-Releases/releases).

As atualizacoes sao baixadas em segundo plano. Por padrao, a instalacao acontece ao encerrar o MusicSafe pelo menu da bandeja.
